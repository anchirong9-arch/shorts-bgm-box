# 🎵 쇼츠 브금 박스 (shorts-bgm-box)

쇼츠·틱톡·릴스 만들 때 바로 쓰는 **무료 소리 도구 한 페이지**입니다.

- 🎵 **브금(BGM) 20곡** — CC0(퍼블릭 도메인) 무료 음악, 검색·미리듣기·MP3/ZIP 다운로드
- ✨ **효과음 89종** — 이 페이지가 브라우저에서 **직접 합성**한 무료 SFX (귀여운 / 편집 기본 / 예능·웃긴 / 게임 / 해외 밈 / 통화·디스코드). 클릭하면 바로 듣고 `WAV`로 저장
- 📁 **내 소리함** — 내 MP3·WAV·OGG·M4A를 올려 이름·카테고리를 붙여 브라우저(IndexedDB)에 저장, 검색·필터·다운로드·삭제, **JSON 백업/복원**
- 🎬 **영상 소리 추출기** — MP4·MOV·WebM에서 소리만 뽑아 파형을 보고 **구간을 잘라** 미리듣기 → 내 소리함 저장 또는 WAV 다운로드

- 사이트: <https://anchirong9-arch.github.io/shorts-bgm-box/>
- 처리 방식: 음원·영상을 **서버로 보내지 않습니다.** 합성·디코딩·저장 모두 브라우저 안에서 끝납니다.

## 라이선스

- **브금 20곡**: CC0 1.0 (Public Domain). 원본 출처 FreePD.com (서비스 종료, <https://archive.org/details/freepd> 보존본). 원본 MP3를 재인코딩 없이 그대로 담았습니다. 곡별 작곡가·경로는 [NOTICE.md](NOTICE.md)와 사이트 하단 표 참고.
- **효과음 89종**: 이 저장소의 `assets/js/sfx-lib.js`가 오실레이터·노이즈·필터·리버브로 **실시간 합성**합니다. 외부 음원 샘플을 쓰지 않으므로 저작권·출처 표기 문제가 없고, 상업적 이용·수익 창출 OK.
- **내 소리함·추출 클립**: 사용자가 올린 파일이므로 권리는 각자에게 있습니다. 이 사이트는 저장·변환만 하고 외부로 보내지 않습니다.


## 기술 메모

- **효과음 합성**: 순수 JS로 샘플을 직접 계산합니다(오실레이터·바이패스 필터·슈뢰더 리버브·엔벨로프). 다운로드는 44.1kHz 16bit 모노 WAV, 미리듣기는 AudioContext 샘플레이트로 렌더링합니다.
- **영상 소리 추출**: `AudioContext.decodeAudioData`로 영상 컨테이너의 오디오 트랙을 디코딩합니다(MP4/AAC, WebM/Opus, MOV 등). 소리 트랙이 없는 영상은 추출할 수 없습니다.
- **내 소리함**: IndexedDB(`shorts-bgm-box` → `clips`)에 Blob을 저장합니다. 브라우저 데이터를 지우면 사라지므로 **백업(JSON)** 을 써 두세요. 백업 파일에는 오디오가 Base64로 들어갑니다.
- **백업 복원**: 같은 id 또는 같은 이름+크기의 항목은 건너뛰고 나머지만 추가합니다(중복 방지).
- 캐시 방지를 위해 `index.html`의 CSS/JS에 `?v=` 버전 파라미터를 붙입니다. 수정 후에는 숫자를 올려 주세요.

## 브금 추가하기

1. CC0 음원을 `assets/bgm/`에 넣습니다.
2. `assets/data/tracks.json`의 `tracks` 배열에 항목을 추가합니다(제목, 작곡가, 카테고리, BPM, 길이, 태그, 원본 경로).
3. `zips/`를 다시 만들고 커밋·푸시합니다.

## 효과음 추가하기

`assets/js/sfx-lib.js`의 `DEFS` 배열에 항목을 추가합니다.

```js
{
  id: 'my-sound', name: '내 소리', cat: 'edit', dur: 0.4, tags: ['태그'],
  desc: '설명', use: '쓰는 곳',
  make: function (e) {
    e.tone({ dur: 0.2, f0: 880, f1: 440, amp: 0.4 });
    e.noise({ dur: 0.15, amp: 0.2, filter: 'bp', f0: 1200, q: 1 });
    e.rev({ mix: 0.2, rt: 0.8 });
  }
}
```

`e.tone`(오실레이터) · `e.noise`(필터 노이즈) · `e.bell` · `e.kick` · `e.snare` · `e.clap` · `e.cymbal` · `e.click` · `e.rev`(리버브)를 조합합니다. `cat`은 `cute` / `edit` / `fun` / `game` / `meme` / `call` 중 하나입니다.
